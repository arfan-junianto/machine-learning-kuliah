Anti-leakage

Preprocessing berada di dalam pipeline dan test set tidak digunakan untuk memilih model.

Reproducible

Seed, split, parameter, metrik, dan artefak hasil disimpan secara eksplisit.

Responsible

Keterbatasan dan disclaimer medis ditampilkan pada laporan serta aplikasi.

Alur proyek mengikuti tugas Bab 14 [ML-MODUL-01, hlm. 89–94]. Dataset UCI/scikit-learn merupakan sumber luar knowledge base.

±90 detik. Bab 14 menerapkan workflow end-to-end. Data Breast Cancer Wisconsin dipahami dan disiapkan, lalu tiga model dibandingkan menggunakan fold dan metrik yang sama. Model dipilih dari cross-validation berdasarkan F2 karena kelas ganas perlu mendapat perhatian lebih. Test set tidak dipakai berulang untuk memilih model; test hanya dibuka setelah pemenang ditentukan. Model dan urutan preprocessing kemudian disimpan sebagai satu bundle untuk aplikasi. Tegaskan bahwa dataset dan implementasi ini untuk demonstrasi akademik, bukan diagnosis medis. Transisi: berikutnya hasil evaluasinya.

Jawaban singkat pertanyaan dosen:
  1. Mengapa GitHub? Untuk versioning, akses publik, dokumentasi, dan reproducibility.
  2. Mengapa Colab? Mengurangi ketergantungan pada setup komputer lokal.
  3. Mengapa Random Forest? F2 CV tertinggi pada perbandingan yang memakai fold dan metrik sama.
  4. Apakah test set dipakai tuning? Tidak; test dikunci sampai model dipilih dari CV.
  5. Mengapa F2? Memberi bobot lebih besar pada recall kelas ganas.
  6. Apakah aplikasi medis? Tidak, hanya demonstrasi akademik dan bukan diagnosis medis.
  7. Bagaimana memastikan kode dapat dijalankan? Notebook mandiri, requirements, test otomatis, dan smoke run.
  8. Apa pengembangan berikutnya? Validasi eksternal, audit kalibrasi/fairness, dan monitoring data drift.
