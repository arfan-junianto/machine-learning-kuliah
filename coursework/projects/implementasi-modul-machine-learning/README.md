## Menjalankan Secara Lokal

Dari **root repository** (`ML/`):

Gunakan **Python 3.11 atau 3.12** untuk setup lokal agar kompatibel dengan paket TensorFlow pada rentang versi proyek. Jika versi Python lokal lebih baru dan TensorFlow tidak tersedia, gunakan Google Colab.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r coursework/projects/implementasi-modul-machine-learning/requirements-dev.txt
jupyter notebook coursework/projects/implementasi-modul-machine-learning/notebooks/
```

Masih dari root repository, jalankan tes struktur dan sintaks notebook:

```bash
.venv/bin/pytest -p no:cacheprovider coursework/projects/implementasi-modul-machine-learning/tests -q
```

Catatan: TensorFlow belum tersedia pada environment lokal repo saat notebook dibuat. Karena itu, pengujian lokal mencakup JSON, sintaks cell, struktur workflow, anti-leakage, dan pipeline data; eksekusi training TensorFlow penuh dilakukan dengan **Run all** di Google Colab.

Notebook klasik Bab 1–11 dapat diuji berurutan tanpa menyimpan output:

```bash
.venv/bin/python coursework/projects/implementasi-modul-machine-learning/scripts/smoke_run_classic_notebooks.py
```

Notebook Bab 1–11 dan 13 dibangun deterministik dengan:

```bash
.venv/bin/python coursework/projects/implementasi-modul-machine-learning/scripts/build_remaining_notebooks.py
```
